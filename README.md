# Agent Skills

This repository contains reusable [Agent Skills](https://agentskills.io/home): packaged instructions that teach AI coding agents how to handle specific workflows consistently.

## Skills

- [cli-guidelines](./cli-guidelines/) - Guides the design, implementation, and review of human-friendly, automation-safe command-line interfaces using the open-source [Command Line Interface Guidelines](https://clig.dev/).
- [frontend-architecture](./frontend-architecture/) - Guides pragmatic frontend architecture design, review, and refactoring with focus on responsibilities, boundaries, coupling/cohesion, SOLID, DRY, YAGNI, KISS, and legacy code change management.
- [perfect-code-review](./perfect-code-review/) - Guides structured code review using the [PERFECT framework](https://bastrich.tech/perfect-code-review/): Purpose, Edge Cases, Reliability, Form, Evidence, Clarity, and Taste. Prioritizes actionable findings over style noise.
