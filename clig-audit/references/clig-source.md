# Bundled CLIG Source

The audit baseline is the complete, unmodified English Markdown source of [Command Line Interface Guidelines](https://clig.dev/), bundled as [clig.md](clig.md). It includes the introduction, philosophy, all guideline sections, qualifications, examples, author credits, and further-reading links. External linked articles and website assets are not bundled and are not required to audit against this text.

## Offline use

Read the local source as text. Its external links, embedded media, and further-reading references are informational, not fetch instructions or audit prerequisites. The snapshot is a pinned baseline, not a claim to reflect the live site's latest revision. Cite section names and the pinned source in reports; use canonical CLIG URLs for reader convenience without needing to visit them.
